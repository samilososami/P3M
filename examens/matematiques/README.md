# Exámenes PAU de Matemáticas (Cataluña)

Cada carpeta es un año. Pulsa en el nombre del fichero para abrir el PDF.

**Cómo leer el nombre del fichero:** `pau_mate` + año en dos cifras + código. 
`jl` = enunciado de junio · `jp`/`jt` = soluciones de junio · `sl` = enunciado de septiembre · `sp` = soluciones de septiembre · 
`o`/`e` (2026) = ordinaria/extraordinaria con enunciado y soluciones juntos · `_tei` = examen del tribunal TEI (otra serie distinta).
